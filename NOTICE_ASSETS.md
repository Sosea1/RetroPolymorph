# Asset attribution

RetroPolymorph uses the Polymorph recipe-selector sprite set derived from the
original Polymorph project by Illusive Soulworks:

https://github.com/illusivesoulworks/polymorph

The upstream project states that its source code and assets are licensed under
GNU LGPL 3.0. RetroPolymorph itself includes the LGPL/GPL license texts in this
source distribution and production JAR metadata.

Upstream sprite names mirrored by RetroPolymorph:
- current_output.png
- current_output_highlighted.png
- output_button.png
- output_button_highlighted.png
- selector_button.png
- selector_button_highlighted.png
