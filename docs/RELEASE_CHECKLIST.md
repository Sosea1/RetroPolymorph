# RetroPolymorph Release Checklist

Checklist to follow before issuing public binary or source releases.

---

## 1. Code Quality & Verification Gates

- [ ] **Clean Build**: Run `./gradlew clean test build --no-daemon --warning-mode all`. Build must complete with 0 failures and 0 warnings.
- [ ] **Full Test Suite**: All unit and characterization tests pass:
  - Adapter contract tests (`AdapterContractTestBase`, `MachineRecipeSelectionAdapterContractTest`, etc.)
  - Ender Crafter dynamic output verification (`EnderCrafterRecipeIdentityTest`)
  - Shared viewer lifecycle reset (`LifecycleResetCharacterizationTest`)
  - Context placement & persistence tests (`SelectorPlacementV2AdoptionTest`)
  - Integration sanity tests (AE2, RS, Tinkers, Forestry, IC2, Thaumcraft, Cyclic, Mekanism, Thermal, XU2)
- [ ] **Zero `catch (Throwable)`**: Verify that no broad `Throwable` catches exist in production code; all exception boundaries catch specific typed exceptions (`ReflectiveOperationException | LinkageError | RuntimeException`).
- [ ] **API Consistency**: All internal contexts and adapters use the public API v1 contracts (`probe`, `getSelectorPlacement`, `getPersistencePolicy`).

---

## 2. JAR Artifact Verification

- [ ] **Manifest & Metadata**:
  - `mcmod.info` version matches release tag (`0.1.0-beta`).
  - `META-INF/LICENSE` is included and contains the complete LGPL/GPL text and asset attribution.
- [ ] **Mixin Configurations & Refmaps**:
  - `mixins.retropolymorph.json` and every declared optional mixin configuration are present in the JAR root.
  - Refmap `mixins.retropolymorph.refmap.json` is generated and valid.
- [ ] **Resource Hygiene**:
  - `assets/retropolymorph/` contains UI textures (`gui/polymorph_widgets.png`, icons).
  - `logo.png` is packaged from `src/main/resources/logo.png`.
  - No build scripts, test classes, or raw markdown documentation files leak into the mod JAR.

---

## 3. Runtime Verification (Cleanroom & Forge)

- [ ] **Cleanroom 0.6.10-alpha**: Deploy `retropolymorph-0.1.0-beta.jar` to mods folder, verify startup without mixin crash.
- [ ] **Cleanroom 0.6.12-alpha**: Deploy `retropolymorph-0.1.0-beta.jar` to mods folder, verify startup and F8 compatibility diagnostic in-game.
- [ ] **Standard Forge 1.12.2 + MixinBooter 11.0+**: Verify mixin application on non-Cleanroom launch.

---

## 4. Documentation & Packaging

- [ ] **README.md**: Synchronized config examples, removed stale config entries (`B:forestry=true`), updated integration list.
- [ ] **ADDON_DEVELOPMENT.md**: Reflects public API v1 `probe()` signature, priority tiers table, and wire-safe recipe key specification.
- [ ] **CHANGELOG.md**: Highlights key features, integrations, and architectural changes for the target release.
- [ ] **Source Archive**: Verify the versioned `-sources.jar` generated by the build.
- [ ] **Manual Changelog**: Paste the relevant `CHANGELOG.md` section into the CurseForge or Modrinth release form.
